Welcome to the "System Diagnostic Utility (SDU)"
It analyzes your PC performance, identifies bottlenecks or throttles and guides optimal upgrade paths.

Features:
-Analyzes system performance and detects bottlenecks.
-Runs full-system stress tests for accurate scoring.
-Compares results with similar systems for context.
-Provides actionable upgrade recommendations and insights.

Tech-Stack:
-Backend: Django, DRF and SQLite
-Frontend: React, TypeScript and TailwindCSS

--- Start Backend (Django) ---
py manage.py runserver
--- Start Frontend (React) ---
npm run dev
